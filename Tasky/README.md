# Tasky

Tasky is a simple and responsive task management application built with React and Tailwind CSS. Users can add tasks by entering a title and description, view them instantly on the screen, and remove them whenever needed.

## Features

- Add a task with a title and description
- Display tasks instantly
- Remove tasks
- Responsive design
- Built using React `useState` hook

## Technologies Used

- React
- Vite
- JavaScript
- Tailwind CSS

## Run the Project

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
